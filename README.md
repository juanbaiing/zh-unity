# 中文套式编辑器

用中文写 Unity 脚本，生成标准 C#，粘进 Unity 就能跑。

给被英文卡住的人用的 —— 不是绕开语法，是绕开「读英文时解析不出套式」这一步。

## 为什么做这个

原话：

> 挂载脚本，互相调用就要靠老程序员的直觉，很容易出现互相调用，最后忘掉然后打补丁修的屎山。

所以除了「中文 → C#」，还做了一张**关系网**：谁调谁、哪个口伸空了、哪个脚本没人挂，摊在一张图上看。

> 我把打开编辑器本身融入了网状图内。

脚本框放大到占满屏幕时，框**里面**就是块编辑器。不是弹窗。

## 现在能干什么

**语言层**

中文套式直接生成 C#。词表按中文教材的译名走，生造词只挑两个字的：

| 中文 | C# |
|---|---|
| 设若（条件） | `if` |
| 遍历（列表 中 x） | `foreach` |
| 重复（n） | `for` |
| 只要（条件） | `while` |
| 公开的类 / 字段 / 方法 | `public class` / `public` 字段 / 方法 |

全角括号、分号、逗号自动归一，字符串里的不管。变量名可以中文，落成 ASCII 走。

**编辑器**

- 块能拖、能嵌套、能连线；托盘里点一下就加一块
- 每个块右键能挂一句注释，注释跟着块走，落到生成代码的行尾
- 中间层并排显示「块经中文写出来是什么样」，和右边 C# 逐行对齐

**关系网**

- 每个场景实例一个框，挂的脚本、露的条件出口、公开变量都长在框上
- 线从脚本行出发，穿到对方的口；连到 Unity 内置组件的口算空头，标出来
- 绕不开的线会自己绕行；判定撞不撞用线段-矩形精确相交，不是采样点
- 断链红虚线，没人挂的脚本标红

**报错**

真编译，不是自己猜。错误的那几个字符底下画红波浪线，悬停出 CS 码和中文解释，点一条会滚到那行、同时点亮生成它的块。

## 怎么装

**两条路，选一条**

### A. 直接下载（推荐，不想碰命令行就走这条）

去 [Releases](https://github.com/juanbaiing/zh-unity/releases) 下 `中文套式编辑器.exe`，双击就跑。

一个文件，60MB（里面带着 .NET 运行时），**不用装任何东西**。

> 唯一的前提：系统得有 WebView2。Win11 自带，Win10 一般也装过了。真没有的话，程序会提示，按提示装一下就行。

### B. 自己编译

**你需要先有两样东西**

| 要什么 | 去哪弄 |
|---|---|
| .NET SDK 8 或更新 | https://dotnet.microsoft.com/download |
| 一个 Unity（或团结引擎）项目 | 已经在用的那个就行，不新建也行 |

> 没有 Unity 项目也能启动，只是没东西可画。

**拿到代码**

不会 git 也行，网页上点绿色的 **Code → Download ZIP**，解压到任意目录。

会用 git：

```
git clone https://github.com/juanbaiing/zh-unity.git
```

**编译**

在解压/克隆出来的那个目录里打开命令行（地址栏输入 `cmd` 回车），执行：

```
dotnet build 编辑器壳
```

第一次会联网下载几个包，等一两分钟。最后一行出现 `0 个错误` 就成了。

**启动**

```
编辑器壳\bin\Debug\net11.0-windows\中文套式编辑器.exe
```

双击也行。

## 第一次打开

窗口是空的，画布上写着 **「还没扫描项目」**。

1. 点顶上的 **「扫描项目」**
2. 弹出选择框 —— 它会自动定位到你上次的项目那一层
3. 选中**你那 Unity 项目的那一层**（就是里面有 `Assets` 和 `ProjectSettings` 的那个文件夹），比如 `我的游戏`，而不是进到 `我的游戏\Assets` 里面去
4. 它会自动找出下面的 Assets，扫一遍脚本、场景、预制体，然后画出关系网

**扫完还是空的？** 点顶上的 **「刷新」** 再来一次。

**画布上只有框、没有连线？** 说明这个项目还没跑过 Unity 插件那一套，只能看到有哪些物体、挂了哪些脚本，看不到谁调用谁。老项目不受影响。

---

## 第一次写

空画布上除了提示，还有一个 **「先随便试试 →」**。

点它会生成一个能跑的样板：

```
类 MyScript
  方法 开始时
    打印 "你好"
```

右边立刻出对应的 C#。改名字、换内容、加块，都随你。

不想用它就直接删掉，自己从左边拖。**左边点一下块就能加到画布上**，拖进虚线框里就是塞进那个盒子。

---

## 存进 Unity

点 **「存到 Unity」**，文件会直接写进你项目的 `Assets` 里。

**⚠️ 然后要切到 Unity，把这个脚本拖到场景里的物体上**——不然它不会跑。这一步 Unity 不会替你做。

## 目录

| 路径 | 是什么 |
|---|---|
| `editor2.html` | 页面本体（实例框、块、连线全在这） |
| `blocks2.js` | 块树 → 中文套式源码 |
| `zh2unity.js` | 中文套式 → C# |
| `translator.js` | 纯文本模式下的一行翻译 |
| `libavoided.js` | 连线绕行（vendored） |
| `编辑器壳/` | WinForms + WebView2 的壳，编译检查、写盘走它 |
| `数据层/` | SQLite 建库灌库，组装画布 JSON |
| `源码扫描/` | Roslyn 扫 Unity 项目 |
| `docs/` | 三份调研：连线怎么绕、前端交互、要解决的痛点 |

## 踩过的坑

几条最容易再踩一次的：

- 页面是编译期嵌进 exe 的。改 html 要重新打包再重编译，光重启没用
- `blocks.js` 是死的，页面加载的是 `blocks2.js`
- 开窗时实例框会被撑成屏幕的 92%，那一个框不能再当连线避让的障碍
- 画线两边判「撞没撞」，用采样点会漏 30px 的薄框

## 还没做

- 多场景分开看（现在只有一张网）
- 点错误跳块时，视野不会跟着过去

## 明确不做

看过效果之后否掉的，别再提：

- 同侧多口分道
- 全局半透明 + 选一个亮一片
- 按缩放尺度分级显示信息量
